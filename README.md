# OnlineBookStore

## Project Overview
OnlineBookStore is a web-based application that allows users to browse, search, and purchase books online. The system provides a simple and user-friendly shopping experience.

## Features
- User Registration and Login
- Browse Books
- Search Books
- Add to Cart
- Order Management
- User Profile Management

## Technologies Used
- Java
- JSP
- HTML
- CSS
- JavaScript
- MySQL

## Installation
1. Clone the repository
2. Import into Eclipse IDE
3. Configure MySQL Database
4. Run on Apache Tomcat Server
